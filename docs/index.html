Documentazione SuitePMI

Installa SuitePMI in locale e segui il lavoro dalla fattura all’incasso, con budget, ore e spese per ogni commessa.

Inizia dall’avvio rapido

Avvio rapido

Servono Node.js 22 o successivo, pnpm 10.28.0 e Docker con Compose. Clona il repository ed esegui i comandi dalla sua radice.

git clone https://github.com/Quarantuno/SuitePMI.git
cd SuitePMI
pnpm install
cp .env.example .env
pnpm db:up
pnpm db:migrate
pnpm dev

Apri l’applicazione locale e registra l’azienda. Per provare l’import con dati di esempio, usa la partita IVA 12345678903 e carica la fattura XML di prova.

Fatture e incassi

In Fatture puoi importare documenti FatturaPA in XML, P7M o ZIP. SuitePMI ricava le rate e le relative scadenze. Apri la fattura per registrare un pagamento, anche parziale.

Le note di credito collegate riducono il residuo. La schermata Crediti scaduti mostra le rate da seguire e il calcolo degli interessi di mora.

Solleciti

In Crediti scaduti scegli Sollecita accanto al cliente, rivedi il testo proposto e salva la bozza. Da lì puoi scaricare il PDF, inviarlo via email o PEC se configurata, o registrare un invio eseguito fuori dall’app.

Durante lo sviluppo, i messaggi finiscono in Mailpit. Per la configurazione di SMTP, PEC e invii automatici, consulta il README del branch stabile.

Cassa

Inserisci il saldo di cassa e banca e seleziona l’orizzonte della previsione. La vista settimanale usa le rate aperte delle fatture emesse e ricevute. Puoi includere i crediti scaduti come incassi attesi nella prima settimana.

Commesse

Crea una commessa per un cliente e indica il budget lordo. Dal dettaglio colleghi le fatture attive del cliente e vedi fatturato, incassi e residuo. In Ore e spese registri il tempo lavorato e i costi.

Su dev-unstable puoi anche modificare nome e budget, impostare una scadenza e filtrare le commesse per stato o ritardo.

Sviluppo e API

Il monorepo contiene il frontend React, l’API NestJS e gli schemi TypeScript condivisi. Con PostgreSQL avviato, puoi eseguire build, controllo dei tipi e test dalla radice.

pnpm build
pnpm typecheck
pnpm test

I test di integrazione usano il database separato suite_test. Trovi le rotte nel riferimento API.
